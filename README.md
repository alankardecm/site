# AM Consultoria — portfólio comercial

React + Vite. Casos de dados, integração e IA, repertório de projetos e referências de investimento de R$ 10 mil, R$ 20 mil, R$ 50 mil e R$ 100 mil.

```bash
npm ci
npm run dev -- --host 127.0.0.1
npm run build
```

- `src/projects.json`: conteúdo dos casos e campos de evidência a completar.
- `src/Home.jsx`: apresentação, filtros, abas e contato por WhatsApp.
- `src/index.css`: layout responsivo, foco e estilos de impressão.
- `docs/PORTFOLIO_COMERCIAL.md`: fontes, critérios editoriais e guia de preenchimento.

As referências de investimento representam novos escopos e não valores cobrados nos projetos. Impactos sem evidência permanecem explicitamente pendentes.
